# LegacyFonts

Fonts that were used before the move to open-licensed fonts. They are kept for reference only and are
**not** packaged into the iOS app or the web build (only `Assets/` is packaged).

| File | Font | Rights holder |
|---|---|---|
| `HGRPP1.TTC` | HG創英角ポップ体 | RICOH Co., Ltd. |
| `calibrib.ttf` | Calibri Bold | Microsoft Corporation |

Their licenses do not allow redistribution as part of an app or a website, so do not copy them back into `Assets/`.

Current fonts (in `Assets/Fonts/`, SIL Open Font License 1.1):
- `MPLUS1p-Bold.ttf` — chemical formulas on the balls (has the subscript digits U+2080-2089)
- `MochiyPopOne-Regular.ttf` — score digits
